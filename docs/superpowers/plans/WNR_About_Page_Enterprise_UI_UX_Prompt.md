# WNR About Us -- Enterprise UI/UX Design Specification Prompt

## Role

Act as a Senior Product Designer, Creative Director, UX Architect,
Motion Designer, Storytelling Designer, Information Designer, and Senior
Frontend Engineer with 15+ years of experience designing Fortune 500
enterprise websites.

Your task is to redesign the **WNR About Us** page.

## Reference Websites

**Primary Reference (About Experience)** -
https://www.concentrix.com/about/

**Secondary Reference (Editorial Storytelling & Motion)** -
https://www.tcs.com/what-we-do/infrastructure-to-intelligence

Study both websites thoroughly.

Analyze: - Storytelling flow - Editorial layout - Visual hierarchy -
Grid system - Whitespace - Typography - Motion language - Scroll
interactions - Image treatment - Hover interactions - Micro
interactions - Accessibility - Responsive behavior

Do **NOT** copy branding, colors, typography, imagery, layouts, icons,
or assets.

Recreate only the quality of the experience using WNR's own design
system.

## Codebase Rules

Before implementing: - Analyze the complete codebase. - Reuse existing
components. - Preserve routing, SEO, accessibility and responsiveness. -
Never rewrite components unnecessarily. - Never break existing
functionality.

## Content Rules

Use ONLY the exact About page content from the project documentation. Do
not rewrite, shorten or replace any copy.

Keep the exact order:

1.  Hero
2.  Awards & Recognition
3.  Why WNR Exists
4.  Mission
5.  Vision
6.  What We Believe
7.  How We Work
8.  Inside WNR
9.  Where We're Going
10. The 2040 Anchor (EduOS)
11. CTA

## Overall Design Direction

The page should feel:

-   Editorial
-   Enterprise
-   AI Native
-   Premium
-   Executive
-   Sophisticated
-   Timeless
-   Human
-   Trustworthy

Never feel like a startup template.

## Hero

Create a cinematic editorial hero with: - Oversized typography - Premium
supporting copy - Editorial imagery - Layered backgrounds - Subtle
animated gradients - Elegant entrance animation - Strong whitespace -
Premium CTA

## Awards & Recognition

Immediately below the hero create a premium editorial Awards section
inspired by Concentrix.

Purpose: Build trust before the company story.

Design: - Split layout - Large award artwork - Editorial copy -
Oversized background graphic - Soft shadows - Rounded corners - Gold
accent details - Premium spacing

Motion: - Fade up - Image reveal - Mask reveal - Hover elevation -
Smooth scroll animation

Future-proof the component for certifications, partnerships and
recognitions.

## Why WNR Exists

Transform "Chaos → Clarity" into a scroll-driven story.

Visualize: WhatsApp + Excel + Emails + disconnected tools → Connected
operational platform.

Use: - Animated nodes - Connector lines - Progressive reveals - Subtle
parallax

## Mission & Vision

Large editorial blocks with: - Strong typography - Supporting visuals -
Elegant dividers - Minimal motion

## What We Believe

Create a dramatic full-width dark section. - Large typography - Slow
reveal - Premium gradients - High contrast - Cinematic composition

## How We Work

Desktop: - Horizontal connected timeline - Animated connectors -
Sequential reveal

Mobile: - Vertical timeline - Animated progress line

## Inside WNR

Dark editorial section. Use: - Architecture sketches - Whiteboards -
Desk photography - Product planning visuals

Never use identifiable employee faces.

## Where We're Going

Three Horizon roadmap with elegant timeline animations and milestone
reveals.

## 2040 Anchor

Most emotional section.

Full-width cinematic band.

Data → Intelligence → Action → Success visual progression.

Large typography. Minimal distractions. Premium storytelling.

## CTA

Large enterprise CTA with primary and secondary actions.

## Motion System

Use: - Scroll Reveal - Fade - Scale - Blur Reveal - Image Reveal -
Clip/Mask Reveal - Line Draw - Stagger - Sequential Reveal - Counter
Animation - Hover Elevation - Ripple Buttons - Floating Micro Motion -
Smooth Section Transitions

Animations must be subtle, GPU accelerated and high FPS.

## Responsiveness

No overflow. No layout shift. Adaptive typography. Touch-friendly.
